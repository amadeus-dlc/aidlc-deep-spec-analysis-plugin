# map後もドメイン固有のコレクション型を保つ

[English](0001-concrete-collection-mapping.md)

公開 `map` は、そのコレクションの要素型の範囲で変換し、同じドメイン固有のコレクション型を返す。各具象クラスがメソッドを宣言し、共通の走査と生成は `protected mapTo` へ委譲する。変換後も固有の操作を利用でき、生成先の判断を具象型で確認できるようにするためである。

汎用の `ImmutableFirstClassCollection` と、異なる要素型へ変換する公開 `map` 契約は削除する。汎用型へのフォールバックを残す案と、すべての呼出側に生成先factoryを要求する案は採用しない。別のドメイン表現が必要な場合は、その型が意味を持つ名前の変換操作を提供し、共通の `mapTo` はprotectedのままにする。

非空コレクションは `of(head, tail)` の生成契約を維持する。設置台帳の `tail` や `filter` が空になり得る場合は、ドメイン値 `ManifestEntry` を保持する `ManifestEntries` を返す。索引やカタログは、変換後の項目から検索用の情報を再構築し、必要な文脈を保持する。部分選択専用の再構築処理で新しい項目を黙って捨ててはならない。構築契約違反とcallbackの失敗は、mapで捕捉せず伝播させる。

[2026-09-06のコレクション操作の判断](../decisions.ja.md#型付きファーストクラスコレクションの操作契約2026-09-06) のうち、mapの汎用型返却をこの判断で置き換える。

`combine(other)` は同じ具象型どうしを結合し、その型を返す。順序を持つコレクションでは左側、右側の順を保ち、集合や索引では既存の重複規則と構築契約を維持する。カタログは左右のmetadataを保持し、矛盾するmetadataを黙って上書きせず拒否する。共通処理はprotectedの `combineTo` に置き、mapと同じ走査上限を適用する。

`equals(other)` と `hashCode()` を共通契約に置く。`equals` は反復順に要素を突き合わせ、長さが違えば等しくないとする。要素の等価関係はドメイン型自身の `equals` に委ねる。`hashCode` は同じ反復順に要素のハッシュを `31 * h + element` で畳み込む。等しいコレクションは必ず等しいハッシュを返す。順序を持たない集合や索引が別の等価関係を要るなら、その型が両方を対で上書きする。

この対は `Equatable` の契約でもある（オーナー裁定 2026-09-07、Javaと同じ`equals`/`hashCode`の対）。`equals` を宣言するドメイン型はすべて `hashCode` を実装し、等価判定が見る値と、ハッシュが畳み込む値を一致させる。ハッシュの計算基盤は `kernel/infrastructure` に置き、文字列はJavaの`String.hashCode`と同じ31倍の畳み込み、真偽値は同じ定数（1231／1237）、`-0`は`0`へ正規化する。畳み込みは32ビット符号付き整数へ戻す。

`count()` は保持する要素数を返す共通の照会操作として提供する。空なら0を返し、走査は他の操作と同じ上限に従う。保持値を配列へ書き出してからその長さを読む経路（`toArray().length`、`[...collection].length`）は、この操作で置き換える。要素数を定数時間で答えられる具象型は `count` を上書きしてよい。既存の15型は保持配列の長さを返す上書きを維持する。

`foldLeft(initial, accumulate)` は共通の集約操作として提供する。反復順に走査し、callbackへ蓄積値と要素の2引数だけを渡す。空なら初期値をそのまま返す。蓄積値の型は要素型とは独立させる。[ScalaのfoldLeft契約](https://www.scala-lang.org/api/2.13.18/scala/collection/IterableOnceOps.html) を参考にしつつ、プロジェクトの走査上限と例外の伝播を維持する。
