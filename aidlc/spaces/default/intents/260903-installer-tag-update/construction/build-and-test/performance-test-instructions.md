# 性能テスト手順

## 適用判定

今回の要件にはレイテンシ、スループット、メモリ、処理時間の定量的な性能目標がないため、性能テストは **N/A** である。CLIプラグインであり、デプロイ済みサービスや負荷モデルも存在しない。

## 参考測定

回帰検知の参考値として全テスト時間だけを記録する。

```bash
cd deep-spec-analysis
/usr/bin/time -p bun test --coverage
```

この値は環境依存で、合否判定や将来の閾値には用いない。性能目標を追加する場合は、対象コマンド、入力規模、percentileまたは上限時間を要件として先に定義する。
