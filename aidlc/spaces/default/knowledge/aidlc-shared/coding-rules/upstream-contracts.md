# 借り物の契約を自分の都合で変更しない

移植元: [amadeus-ngの同名規則](https://github.com/amadeus-dlc/amadeus-ng/blob/537c4e56a838a4cb28f6564d4c0add1d4adfe915/aidlc/spaces/default/knowledge/aidlc-shared/coding-rules/upstream-contracts.md)。2026-09-05にTypeScriptと当該の裁定へ適用し直した版。

## 原則

外部ライブラリやAI-DLC本体には、それぞれが所有する契約がある。こちらのモデルに合わないという理由だけで、相手の型・動詞・エラーの意味を変更しない。

| 関係 | 扱い |
| --- | --- |
| 相手の契約に従う | 契約をそのまま利用し、意味を勝手に付け替えない |
| 腐敗防止層で隔てる | adapterで自分のドメインへ変換し、型や失敗の意味の対応を明示する |

## 契約をローカルに写す場合

- 誰が正本を所有しているか、どの版を写したかを記録する。
- コピーした型やinterfaceを、相手との互換性を持つ契約だと扱うなら、その同形性を検証する。
- 変更が必要なら、境界での変換か、自分が所有する別の契約として明示する。
- バージョン更新時は実際の契約を確認する。記憶や古い記述だけで更新しない。
- 正常系だけでなく、エラー・不在・タイムアウトなどの対応も確認する。

このプラグインの契約1〜4、findingsのgolden、stdout verdictなど、既存の公開契約を維持する。今回の共有規則は借り物のAPIではなく、採用範囲を明示した設計ガイドの移植である。
適用範囲と優先関係は[共有規則の入口](README.md)を参照。
