# 可変性と所有権を隠さない

移植元: [amadeus-ngの同名規則](https://github.com/amadeus-dlc/amadeus-ng/blob/537c4e56a838a4cb28f6564d4c0add1d4adfe915/aidlc/spaces/default/knowledge/aidlc-shared/coding-rules/interior-mutability.md)。2026-09-05にTypeScriptと当該の裁定へ適用し直した版。

## 原則

シグニチャと操作の名前から、状態が変わるか予想できる設計にする。照会の裏で共有状態を書き換えたり、返した配列やMapを通じて内部状態が変わったりする構造を避ける。

- 値オブジェクトは不変にする。可変な入力は、所有権を切り離す必要がある場合にコピーする。
- `readonly`だけで深い不変性を保証したと考えない。公開した参照から不変条件が破れないか確認する。
- 可変集約の更新は、その集約のコマンドへ集約する。読み取り操作と区別する。
- 共有が必要なら、その必要性・同期の責務・生存期間を明記する。将来使うかもしれないという理由で同期ラッパーを先に作らない。
- ロックの所有と解放は資源を管理するadapterへ閉じる。ガードを不用意に外へ出さず、例外時も解放する。
- 値のコピーに見える操作で、同じ可変状態を指す別ハンドルを配らない。

移植元の`RefCell`・`SharedLock`・`*Shared`に関するRust固有の実装指定は持ち込まない。TypeScriptでは参照の共有、非同期処理、既存のロック機構について同じ所有権の問題を点検する。
適用範囲と優先関係は[共有規則の入口](README.md)を参照。
